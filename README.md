# Aprendendo TypeScript

Este projeto contém exemplos práticos para aprender e comparar TypeScript com JavaScript.

## Estrutura do Projeto

- `hello_world/`: Exemplo básico de TypeScript e JavaScript.
- `tipos_dados/`: Exemplos de tipos primitivos, arrays, objetos, funções, tuplas e uso de type annotation em TypeScript.
- `javascriptXtypescript.md`: Documento comparando as principais diferenças entre JavaScript e TypeScript.

## Como executar os exemplos

1. Instale as dependências:

   ```powershell
   npm install
   ```

2. Execute um arquivo TypeScript com:

   ```powershell
   npx ts-node tipos_dados/tipos.ts
   ```

3. Para compilar TypeScript para JavaScript:

   ```powershell
   npx tsc
   ```

## Principais conceitos abordados

- Type Annotation
- Tipos primitivos (`number`, `string`, `boolean`, `bigint`)
- Arrays tipados
- Objetos tipados
- Funções com tipos
- Tuplas
- Diferenças entre TypeScript e JavaScript
